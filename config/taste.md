# Taste: hard preferences

The owner edits this file by hand. The scout agent reads it but never writes it. Preferences the agent learns from decisions go in `data/taste.json` (generated) instead.

## Always prefer
- Resources that directly help build a portfolio: case-study layouts, project showcases, typography, motion, and hero visuals.
- Output you can use on a paid client site (clear license).
- Code that drops into React/Next.js/Tailwind, or an AI coding agent (MCP, CLI, llms.txt), when the resource is code.

## Avoid
- Flutter/native-only packages.
- General-purpose AI agents that aren't design tools.
- Quote-only enterprise software.
- Dated illustration styles.
- Link farms, SEO listicles, and "top 100 tools" roundups.
